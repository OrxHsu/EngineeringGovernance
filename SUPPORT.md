# Support

Use GitHub Discussions for usage questions and GitHub Issues for reproducible
bugs or scoped improvements. Include the release version, Node/pnpm versions,
the exact command, and a redacted error or evidence summary.

Do not post credentials, private paths, personal data, or security
vulnerability details publicly. Security reports belong in `SECURITY.md`.

This project does not promise a response time or support for unreleased,
modified, or historical beta runners.
